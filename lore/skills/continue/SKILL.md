# Continue

1. Read the supplied plan or the most recent plan identified in the conversation. If several candidates remain and no evidence distinguishes them, ask which one while performing independent read-only checks.
2. Reconcile completion markers with the current files and verification evidence. A commit or successful edit alone does not prove a task complete. Preserve later user corrections and local changes.
3. Find the next unblocked acceptance criterion. Restore task state with the host tracker or a brief checklist; do not require a vendor-specific session ID or task API.
4. Execute and verify that task, then continue the authorized plan. Do not request approval already given or redo checks unless code changes, failures, or unresolved concerns justify it.
5. Report the delivered result and any concrete blocked boundary.
