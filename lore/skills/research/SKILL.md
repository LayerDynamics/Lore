# Research

1. State the question, required decision, constraints, and evidence threshold. Inspect relevant local documentation and source before assuming architecture or installed capabilities.
2. Use available research tools or connectors. Verify unstable facts and current runtime contracts against official documentation or source. If browsing is unavailable, report that boundary and keep offline findings distinguishable.
3. Compare sources and actual behavior. Record exact versions when material, publication dates when relevant, and direct source links. Separate quoted claims, observed behavior, and inference.
4. Produce the decision or implementation guidance the user requested. Do not turn a narrow question into an unrelated framework or require a particular browser engine.
5. If implementation is authorized, use the findings to complete it. Otherwise provide the evidence and unresolved questions without claiming unperformed validation.
