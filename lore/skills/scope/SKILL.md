# Scope

1. Read the original outcome, authorizations, constraints, and subsequent corrections. Preserve the objective across turns unless the user explicitly replaces it.
2. Compare the current repository, files, planned actions, and delivered artifacts with that outcome. Verify that an installation copy is not being mistaken for the source codebase.
3. Identify omissions and unrelated changes. Complete omitted authorized work; leave unrelated user edits intact. Do not perform cleanup merely because an adjacent issue exists.
4. If the current work targets the wrong object, acknowledge it, undo only your own reversible changes where appropriate, and move to the actual target.
5. State the next concrete action and continue. Ask for clarification only when evidence cannot resolve a material ambiguity.
